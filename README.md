# Oficina XV Motos

Site estático (HTML, CSS e JavaScript puros). Não precisa de build.

Endereço publicado: https://voltechbr.github.io/xv-motos/

## Publicar no GitHub Pages
1. Envie **todo o conteúdo desta pasta** (index.html, assets/, .nojekyll) para a raiz do repositório `xv-motos`.
2. Em *Settings > Pages*, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.

## Estrutura
- `index.html`
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/img/` (logo, fotos da oficina e da galeria, poster do vídeo)
- `assets/video/hero.mp4`

Todos os caminhos são relativos e funcionam no subdiretório `/xv-motos/`.
